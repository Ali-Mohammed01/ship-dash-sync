# نظام إدارة شحنات الوقود - HTML Version

## نظرة عامة
هذا المشروع هو نسخة HTML + CSS + Bootstrap + JavaScript من نظام إدارة شحنات الوقود الأصلي. تم تحويله من React + TypeScript إلى تقنيات الويب التقليدية.

## الميزات
- ✅ صفحة رئيسية جذابة مع Hero Section
- ✅ لوحة تحكم العميل لإنشاء وتتبع الطلبات
- ✅ لوحة إدارة الشركة لمراجعة الطلبات
- ✅ لوحة تحكم السائق لتحديث حالة التسليم
- ✅ نظام دفع وهمي
- ✅ تصميم متجاوب (Responsive Design)
- ✅ واجهة باللغة العربية
- ✅ حفظ البيانات محلياً (Local Storage)

## التقنيات المستخدمة
- **HTML5** - هيكل الصفحات
- **CSS3** - التصميم والتنسيق
- **Bootstrap 5.3.2** - إطار العمل للتصميم
- **Bootstrap Icons** - الأيقونات
- **JavaScript (ES6+)** - التفاعل والمنطق
- **Local Storage** - حفظ البيانات

## كيفية التشغيل
1. **تحميل الملفات**: تأكد من تحميل جميع الملفات في مجلد واحد
2. **فتح المتصفح**: افتح ملف `index.html` في أي متصفح ويب حديث
3. **البدء**: ابدأ بتصفح النظام وإنشاء طلبات شحن جديدة

## دليل الاستخدام

### 1. الصفحة الرئيسية
- تعرض نظرة عامة على النظام
- روابط للوصول إلى الأقسام المختلفة
- تصميم جذاب مع Hero Section

### 2. لوحة تحكم العميل
- إنشاء طلبات شحن جديدة
- تتبع حالة الطلبات الموجودة
- تأكيد التسليم عند اكتماله

### 3. إدارة الشركة
- مراجعة الطلبات المعلقة
- قبول أو رفض الطلبات
- تحديث حالة الطلبات

### 4. لوحة السائق
- عرض التسليمات المخصصة
- تحديث حالة التسليم:
  - تم الاستلام
  - في الطريق
  - تم التسليم

### 5. نظام الدفع
- نموذج دفع وهمي
- حساب التكلفة التقديرية
- معالجة الدفع مع رسائل التأكيد

## حالات الطلبات
```
في الانتظار → مقبول/مرفوض
     ↓
مقبول → تم الاستلام → في الطريق → تم التسليم → مؤكد
```

## الميزات التقنية
- **تصميم متجاوب**: يعمل على جميع الأجهزة
- **واجهة عربية**: دعم كامل للغة العربية
- **حفظ محلي**: البيانات محفوظة في Local Storage
- **تحقق من البيانات**: التحقق من صحة المدخلات
- **رسائل تأكيد**: إشعارات للمستخدم
- **تنسيق تلقائي**: تنسيق أرقام البطاقات والتواريخ

## التخصيص
يمكنك تخصيص النظام من خلال:
- تعديل ملف `assets/css/style.css` للألوان والتصميم
- تحديث ملفات JavaScript لإضافة ميزات جديدة
- تغيير النصوص في ملفات HTML

## المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- لا حاجة لخادم ويب - يعمل محلياً
